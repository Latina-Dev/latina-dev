# Member writing

Blog posts members published on their own sites, listed at [latina.dev/writing](https://latina.dev/writing).

A daily GitHub Action reads the feed in each member's `blog` profile field and writes one file per member here, `<member-slug>.json`, through a pull request. Don't edit these by hand: the next run overwrites them. The format is in [docs/pages/member-writing.md](../../docs/pages/member-writing.md).
