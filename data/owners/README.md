# Profile owners

Each file here links a LinkedIn sign-in to the profile that member may edit on
[latina.dev/profile](https://latina.dev/profile). The filename is the profile slug,
e.g. `frances-coronel.txt`, and the file holds the SHA-256 of the member's
LinkedIn account id. One file per profile means only one account can ever own
it: two pending claims on the same profile conflict, so only one can merge.

Files are added by the pull requests that the profile form opens, after an
organizer approves them in Slack. Delete a file to unlink that account.
