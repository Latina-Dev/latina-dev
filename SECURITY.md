# Security Policy

## Reporting a Vulnerability

Please don't open a public issue for security problems. Report them privately through [GitHub's private vulnerability reporting](https://github.com/Latina-Dev/latina-dev/security/advisories/new) instead.

We aim to acknowledge reports within 7 days and to share a fix or a plan within 30 days. Once a fix ships, we publish an advisory and credit you unless you'd rather stay anonymous.

## Supported Versions

Only the live site at [latina.dev](https://latina.dev), built from the `main` branch, receives security fixes.
